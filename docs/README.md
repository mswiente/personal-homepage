# Dokumentation

Aufbau und Regeln folgen dem [Dokumentations-Standard](https://github.com/mswiente/coding-standards/blob/main/standards/documentation.md). Kurzfassung:

- `specs/`: Soll-Stand je Bereich (SPEC-NNNN). **Lebende Dokumente:** Eine Verhaltensänderung ist erst fertig, wenn die Spec sie beschreibt.
- `adr/`: Entscheidungen und ihre Gründe (ADR-NNNN). Nach der Annahme unveränderlich.
- `backlog.md`: Todos und Ideen, eine Zeile pro Eintrag.
